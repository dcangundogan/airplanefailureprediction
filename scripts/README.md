# Scripts

Runnable Python scripts live here.

- `turbofan_final_model.py` uses local `../data` by default and writes figures to `../outputs`.
- `patchtst_xgboost_cmapss.py` accepts `--base data` or an absolute data path.
- `engine_level_mil_tcn_bigru_xgboost.py` resolves the project `data/` folder automatically.
- `architecture_diagram.py` writes the diagram to `../assets/images/architecture_diagram.png`.
